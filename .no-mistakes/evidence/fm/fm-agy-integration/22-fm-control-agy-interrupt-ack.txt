# Scenario: bin/fm-control.sh interrupt on an agy task reports the cancellation
# claim from agy's rendered row, confirms nothing when that row never appears,
# and never counts a row that was already on screen before the interrupt.
# Product: the real bin/fm-control.sh over a real tmux server on a private lab
# socket, with the real tmux backend classifier. The pane runs a lab stand-in for
# the Antigravity TUI (a copy of bash named `agy`, so the backend's process
# classification sees agy) that renders agy's verified cancellation row on
# Escape during a turn; the real agy TUI was not driven, to avoid writing trust
# settings into the operator's agy configuration.
