# Scenario: Gemini account fallback (Neon first account -> second account) and
# conversation affinity (a resumed conversation stays on the account that owns
# it, and is refused rather than silently moved when that account cannot run).
# Product: the real bin/fm-agy-pool.sh, executed by the operator against the
# real sudo pool accounts from /etc/firstmate/gpro-pool.conf-equivalent lab
# config (piyushjiit, piyushk). AGY_BIN is a lab stand-in for the Antigravity
# CLI that records the invocation it received and exits with agy's real quota
# line for the named account; no Gemini quota is spent.
#
# pool.conf: piyushjiit, piyushk
# models.conf: *neon* piyushjiit,piyushk (order = failover order)

## 1. quota on the first account hands the same call to the second
